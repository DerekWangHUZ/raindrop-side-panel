如何获取 Test Token

  1. 打开 Raindrop.io 的设置。
  2. 进入“集成 → 开发者”页面。
  3. 创建开发者应用，然后点击 Create test token。
  4. 复制生成的 Test Token。
  5. 粘贴到上方，点击“验证并保存”。

如果你主动撤销、重新生成 Token，或删除对应开发者应用，原 Test Token 会失效。若 Raindrop 后续调整入口，以其开发者文档为准。
